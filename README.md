Sistema IoT avanzado para automatizar el mezclado de pintura VINILO con capacidad de generar 36+ colores. 
Controlado mediante ESP32 con 5 bombas hidráulicas (3 colores primarios + blanco + limpieza), sensores ultrasónicos HC-SR04 
para monitoreo de niveles en tiempo real, backend Python Flask para gestión de recetas, y interfaz gráfica Tkinter 
con tema Dark Mode Neon de alto contraste. Almacenamiento local en SQLite con envío de histórico a Azure.
